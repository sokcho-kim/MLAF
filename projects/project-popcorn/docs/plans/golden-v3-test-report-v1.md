## 4. FP 근본 원인 분석

### 4-1. 공통 패턴: "허용 vs 의무" 오판

FP 10건 모두 동일한 패턴을 보임:

```
[기존 법률] action_modality = "허용" (~할 수 있다)
[신규 법안] action_modality = "의무" (~하여야 한다)
→ LLM 판정: "규제 수준 역전" → C=0.85
```

**문제:** 주체가 완전히 다른데도 action_modality 차이만으로 충돌 판정.

### 4-2. 대표 사례: golden_26 (노인복지법) vs 산업발전법 제4조

```
[기존] 산업발전법 제4조
  Subject: 산업통상부장관
  Action: 중ㆍ장기 산업발전전망을 수립할 수 있다
  Action_modality: 허용

[신규] 노인복지법 개정안
  Subject: 노인 관련 보건ㆍ복지 기관의 장
  Action: 노인학대 예방 교육을 실시하고 결과를 제출하여야 한다
  Action_modality: 의무
```

- **Subject**: 산업통상부장관 vs 노인복지기관장 → **완전 불일치**
- **Action**: 산업발전전망 수립 vs 노인학대 예방 교육 → **완전 다른 영역**
- **LLM 판정**: C=0.85 (CRITICAL) → **명백한 오판**

### 4-3. Hard Rule 2 미작동 원인

V2 프롬프트의 규칙 2: "Subject가 완전히 다른 대상이면 → C ≤ 0.3"

**미작동 이유 추정:**
1. Few-shot에서 "주체 불일치 + 의무 vs 허용" 조합의 예시가 없음
2. "허용 vs 의무" 패턴이 Few-shot 예시 1(인가 vs 신고)과 유사하여 action 비교가 주체 규칙을 override
3. gpt-4o-mini의 instruction following 한계: 복수 규칙 간 우선순위 판단 미숙

### 4-4. FP를 유발하는 "허용" 조문들

산업발전법에서 반복적으로 FP를 유발하는 조문:

| 조문 | 내용 | FP 유발 횟수 |
|------|------|-------------|
| 제4조 | "산업발전전망을 수립할 **수 있다**" | 5회 |
| 제8조 | "지식서비스산업을 육성할 **수 있다**" | 2회 |
| 제9조 | "지역진흥사업을 할 **수 있다**" | 1회 |
| 제10조 | "사업전문화 유도시책을 수립할 **수 있다**" | 1회 |
| 제24조 | "사모집합투자기구를 설정할 **수 있다**" | 1회 |

→ `action_modality = "허용"`인 조문은 어떤 "의무" 법안과도 C=0.85를 생성하는 **독소 조문** 역할.

## 5. FN 상세 분석

### 5-1. golden_1, golden_2: 정의조 fallback 문제

| 항목 | golden_1 | golden_2 |
|------|----------|----------|
| 법안 | 탄소중립법 개정 | 중대재해법 개정 |
| 비교 법률 | 에너지법, 에너지이용합리화법 | 중대재해법 |
| 비교된 조문 | **제2조 (정의)** | **제2조 (정의)** |
| 원인 | 실체 규정 조문이 매칭 안됨 | 실체 규정 조문이 매칭 안됨 |

`find_relevant_articles`의 `extract_target_articles`가 법안 요약에서 조문 번호를 추출하지 못하면, fallback으로 첫 3개 조문을 선택하는데, `SKIP_ARTICLE_TITLES`로 정의조/목적조를 건너뛰어도 일부 법률은 남은 앞 조문이 여전히 비실체 조문임.

**golden_1의 경우:** 에너지법 fallback 시 제3조(기본이념) 건너뛴 후 다음 조문인 제2조(정의)만 남음 → 정의조만 비교.

### 5-2. golden_4: 매핑 부적절

약사법 개정안(안전상비의약품 24시간 운영 조건 예외)은 보건복지부 소관이며, 산업부 법률(산업집적법, 제품안전기본법)과는 실질적 규제 충돌이 없음. 이 건은 Golden Set 매핑 자체가 "약한 연관"으로 설정된 Hard 난이도.

### 5-3. golden_12, golden_13: NLI 한계

임금채권보장법(고용노동부)과 군인사법(국방부)은 산업부와 "간접적" 영향만 있어, 조문 단위 NLI로는 감지 불가능. 키워드(에너지, 산업, 전력, 자원) 기반 연관성은 있으나, 법률 조문 간 논리적 충돌은 존재하지 않음.

## 8. 개선 방향

### 8-1. 단기 (FP 해결) — NLI 프롬프트 V3

**핵심:** 규칙 2(주체 불일치) 강화

| 방안 | 설명 | 기대 효과 |
|------|------|----------|
| A. 규칙 우선순위 명시 | "주체가 다르면 action_modality 차이는 충돌 근거 불가" 명시 | FP 대폭 감소 |
| B. 허용 vs 의무 전용 규칙 추가 | "허용 vs 의무는 동일 주체+동일 영역일 때만 충돌" | FP 독소 조문 제거 |
| C. Few-shot 보강 | "주체 불일치 + 허용 vs 의무 → N≥0.8" 예시 추가 | LLM instruction following 강화 |
| D. 2단계 파이프라인 | 1단계: 주체 일치 판정 → 2단계: NLI (주체 일치 시에만) | 구조적 FP 차단 |

| 방안 | 해당 FN | 설명 |
|------|---------|------|

| KG 스코어 결합 | golden_12, 13 | NLI 스코어 + KG 경로 스코어 하이브리드 |
| Golden Set 매핑 재검토 | golden_4 | 약사법-산업부 매핑의 적절성 재평가 |

### 8-3. 장기 — 모델 업그레이드

| 방안 | 설명 |
|------|------|
