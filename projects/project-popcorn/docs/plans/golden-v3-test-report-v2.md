## 4. 핵심 분석: 왜 FP는 해결되고 TP는 무너졌는가

### 4-1. V3 프롬프트의 성공 — FP 완전 제거

V3 게이트 구조가 의도대로 작동:

```
[판단 흐름]
Subject 비교 → "불일치" → [STOP] → C ≤ 0.2 → Action 비교 스킵
```

V2에서 FP를 유발하던 "산업통상부장관(허용) vs 노인복지기관장(의무) → C=0.85" 패턴이 V3에서는:
- Subject: "불일치" → 규칙 2 [STOP]
- Action: "무관 (규칙 2 적용 — 주체 불일치 시 Action 비교 무의미)"
- **C = 0.10**, N = 0.90

### 4-2. V3 프롬프트의 실패 — TP 대량 회귀

**근본 원인: "교차 도메인 영향" 과제와 "주체 일치" 규칙의 구조적 충돌**

이 Golden Set의 TP 정의:
> "타 부처 법안이 산업부 소관 법률에 영향을 미치는 경우"

즉, TP 케이스는 **본질적으로 주체가 다를 수밖에 없음**:
- 기후위기법(기상청장) → 에너지법(산업통상자원부장관)
- 임금채권보장법(고용노동부장관) → 산업발전법(산업통상부장관)
- 애니메이션산업법(문체부 관련 사업자) → 산업융합촉진법(산업통상부장관)

V3 규칙 2가 이 모든 쌍을 "주체 불일치 → C≤0.2"로 처리하여, **의도한 교차 도메인 충돌 감지가 불가능해짐**.

### 4-3. 유일한 TP 성공 — golden_5의 특수성

golden_5가 성공한 이유:
```
[기존] 신에너지 및 재생에너지법 제26조
  Subject: 국가 또는 지방자치단체
[신규] 국유재산특례제한법 개정안
  Subject: 국가 및 지방자치단체
```

"국가 또는 지자체" vs "국가 및 지자체" → V3 유사 주체 예외 규정에 해당 → 규칙 2 비적용 → Action 비교 진행 → C=0.85.

이 케이스만 **두 법률의 Subject가 실질적으로 동일**했기 때문에 게이트를 통과.

## 5. 구조적 한계 진단

### 5-1. NLI 단독으로 "교차 도메인 영향"을 감지할 수 없는 이유

| 측면 | 동일 도메인 충돌 | 교차 도메인 영향 |
|------|----------------|----------------|
| Subject | 동일/유사 | **다름** |
| 규제 영역 | 동일 | **다름** |
| 충돌 유형 | 직접적 (법적 모순) | 간접적 (정책 영향) |
| NLI 감지 가능성 | **높음** | **낮음** |

교차 도메인 영향은 "법률 조문 간 논리적 모순"이 아니라 "정책 파급효과"에 가까움. NLI(자연어 추론)는 전자에 최적화된 도구.

### 5-2. 딜레마: 규칙 2 강도 vs TP 감지

| 규칙 2 설정 | FP | TP | F1 | 문제 |
|------------|----|----|-----|------|
| C ≤ 0.3 (V2) | 10 | 10 | 0.57 | FP 과다 |
| C ≤ 0.2 (V3) | 0 | 1 | 0.13 | TP 소멸 |
| 규칙 2 없음 | ≥10 | ≥10 | ≤0.57 | V2 이하 |

규칙 2의 강도를 어떻게 조정하든 FP-TP 트레이드오프를 동시에 해결할 수 없음. **NLI 스코어 단독으로는 교차 도메인 영향 감지에 구조적 한계가 존재**.

### 5-3. 임계값 0.1에서의 가능성

V3 + 임계값 0.1 조합:
```
Precision: 0.4643  |  Recall: 0.8667  |  F1: 0.6047
```

이 설정에서 TP 13/15건 감지(golden_2, golden_13만 FN). 다만 FP 15건 중 2건이 0.1~0.2 사이에서 FP 발생. **V2 F1(0.5714)보다 소폭 우위이나 Precision 약화**.

## 7. 개선 방향 (재설정)

### 7-1. NLI 역할 재정의

NLI는 **"동일 규제 영역 내 법적 모순 감지"**에만 사용하고, 교차 도메인 영향 감지는 **별도 모듈**로 분리.

### 7-2. 멀티 스코어 파이프라인 (권장)

```
법안 → [Stage 1: 도메인 연관성] → [Stage 2: NLI 충돌 분석]
         ↓                          ↓
    키워드/임베딩 유사도          조문 단위 NLI (V3)
         ↓                          ↓
    domain_score              contradiction_score
         ↓
    [Stage 3: 최종 판정]
    final_score = α·domain + β·nli
```

| Stage | 역할 | 도구 |
|-------|------|------|
| Stage 1 | "이 법안이 산업부 소관과 관련이 있는가?" | 키워드 매칭, 임베딩 유사도, KG 경로 |
| Stage 2 | "관련 있다면, 어떤 조문과 어떤 충돌이 있는가?" | NLI V3 (동일/유사 주체 간) |
| Stage 3 | 최종 분류 | domain + nli 가중합 |

**기대 효과:**
- Stage 1이 "산업부 관련" TP를 캐치 → FN 해소
- Stage 2(NLI V3)가 정밀 충돌 분석 → FP 방지
- 각 모듈이 자기 역할에 집중

### 7-3. 단기 대안: NLI V3 + 임계값 0.1

멀티 스코어 파이프라인 구축 전 즉시 적용 가능한 조합:
- NLI V3 프롬프트 유지 (규칙 2 게이트 정확 작동)
- 임계값을 0.1로 낮춤
- **F1 0.6047** (V2 대비 +5.8%)
- 단, Precision 0.4643으로 FP 일부 발생 (허용 가능 수준인지 판단 필요)

### 7-4. 프롬프트 V3 유지/롤백 판단

| 선택지 | 장점 | 단점 |
|--------|------|------|
| **V3 유지 + 임계값 0.1** | 최고 F1(0.6047), Recall 86.7% | Precision 46.4% |
| **V2 롤백 + 임계값 0.3** | TP 10건 유지 | FP 10건 유지, F1 0.5714 |
| **V3 유지 + 멀티스코어** | FP 0 + TP 회복 기대 | 추가 개발 필요 |

## 8. 결론

### 8-1. V3 프롬프트 평가

- **성과**: 규칙 2 게이트가 완벽 작동하여 FP 10건 → 0건. 프롬프트 엔지니어링 목표 자체는 달성.
- **한계**: 교차 도메인 영향 감지는 NLI 단독으로는 구조적 한계. "주체 불일치 = 무관" 규칙과 "타 부처 법안 영향 감지" 목표가 근본적으로 충돌.
- **핵심 교훈**: NLI는 "논리적 모순 감지" 도구이지, "정책 파급효과 감지" 도구가 아님. 후자를 위해서는 도메인 연관성 판단이 선행되어야 함.

### 8-2. 다음 단계 우선순위

1. **[P0] 즉시 적용**: NLI V3 + 임계값 0.1 조합 (F1 0.6047, 최선의 단일 모델 성능)
2. **[P1] 멀티 스코어 파이프라인 설계**: domain_score + nli_score 결합 구조
3. **[P2] Stage 1 구현**: 키워드/임베딩 기반 도메인 연관성 스코어
4. **[P3] 조문 매칭 개선**: golden_1, golden_2의 정의조 fallback 문제
